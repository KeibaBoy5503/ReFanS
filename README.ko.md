## 🌐 소개

**ReFanS**는 WPF(.NET 10)로 만든 데스크톱 애플리케이션으로, 비주얼 보드, 오디오·비디오 플레이어, 타이포그래피, 레퍼런스 파일 관리를 하나로 합쳤습니다. 빠른 Masonry 레이아웃, 실시간 오디오/비디오 스크러빙, 색상순으로 정렬되는 계층형 태그를 결합했습니다.

음악, 효과음, 이미지/비디오, 폰트, URL, 문서, 큐레이션 카드 등을 한곳에서 시각적으로 정리, 태그하고 분류할 수 있는 이미지보드 & 레퍼런스 관리 프로그램입니다.

## ✨ 핵심 기능

### 1. 🖼️ Masonry 이미지보드 & 멀티 포맷 라이트박스
* **Masonry 그리드 & 큐레이션 뷰:** 큐레이션 카드와 테두리 없는 이미지보드 모드를 끊김 없이 전환합니다.
* **즉시 라이트박스(`Space` / `더블클릭`):** 고해상도 이미지, 애니메이션 GIF, 동영상(`MP4`/`WebM`), PDF 문서(`WebView2`), 서식이 있는 마크다운(`.md`) 노트를 미리 볼 수 있습니다.
* **편집 작업 공간(라이트박스에서 `Space`):** 큰 화면에서 레퍼런스의 자세한 설명이나 프로필을 입력할 수 있습니다.
* **자유로운 수동 정렬:** 수동 정렬 모드에서 갤러리 안의 카드를 드래그 앤 드롭해 무드보드를 원하는 순서대로 배치하거나, 왼쪽 폴더로 끌어다 놓을 수 있습니다.

### 2. 🎧 미디어 미리보기 & Apple Music 메타데이터 연동
* **미디어 미리보기 플레이어:** 가운데 이미지보드에서 미디어 파일(`MP3, WAV, MP4`)을 재생합니다. 라이트박스 화면에서 크게 재생할 수도 있습니다.
* **오디오 이중 파형:** `.wav`, `.mp3` 파일의 Peak + RMS 파형을 자동으로 그려 주고, 클릭하고 드래그하면 프레임 단위로 즉시 이동(스크러빙)할 수 있습니다.
* **Apple Music / iTunes API 검색:** 고해상도 앨범 아트워크, 발매 연도, 작곡가 메타데이터, 30초 오디오 미리듣기를 자동으로 가져옵니다.

### 3. 📁 인터랙티브 계층 구조 · 100색 팔레트 · RGB 피커
* **스마트 폴더 드래그:** 폴더를 끌어 순서를 바꾸거나(위/아래 가장자리), 다른 폴더의 가운데에 놓아 하위 폴더로 넣을 수 있습니다.
* **10x10 엄선 팔레트 + 2D RGB 스펙트럼:** 폴더 아이콘, 폴더 글자색, 계층형 태그(`상위/하위태그`)의 색을 100가지 프리셋(비비드, 파스텔, 그레이 톤)이나 실시간 RGB 스펙트럼 피커로 지정합니다.
* **라이브러리 분류:** 라이브러리가 파일 형식별로 자동 분류합니다.

### 4. 🏷️ 태그 · 필터 관리, 북마크, 파일 잠금
* **태그 드래그 앤 드롭:** 왼쪽의 태그를 파일로 끌어다 놓으면 태그를 빠르게 적용할 수 있습니다.
* **태그 관리:** 태그의 이름, 색상, 계층을 한 창에서 관리합니다.
* **북마크 & 파일 잠금:** 오른쪽 위의 버튼으로 파일을 북마크하고 잠글 수 있습니다(폴더 잠금도 가능). 파일이나 폴더가 수정되지 않도록 보호합니다.

### 5. 🔍 고급 검색 & 이미지 색상 추출
* **고급 검색:** 검색창 아래의 체크박스로 검색할 항목(`폴더 / 제목 / 태그 / 파일 형식 / 생성일`)을 골라 검색할 수 있습니다.
* **이미지 색상 추출:** 이미지 파일의 대표 색상 5가지를 추출해 보여 줍니다. 각 색상 코드는 클립보드에 복사할 수 있고, 필터 목록에 태그로 등록되어 관리할 수 있습니다.

### 6. 📸 화면 & 영역 캡처 도구
* **전체 화면(`📷`) & 영역 자르기(`✂️`) 캡처:** 창을 자동으로 최소화하고 화면 전체 또는 드래그로 지정한 영역을 캡처합니다. 대표 색상 견본도 추출해 바로 레퍼런스로 등록합니다.
* **썸네일 교체:** 클립보드에 복사한 이미지를 이용해 썸네일을 빠르게 바꿀 수 있습니다.

### 7. 🎨 커스텀 테마 & 3개 언어(설정 유지)
* **기본 테마 4종:** `Default Dark`, `Gray Tone`, `Pure White`(자동 대비 글자색), `Pastel Purple`.
* **커스텀 테마:** 팔레트나 RGB 맵에서 색을 고르거나 이미지 파일에서 배경을 고르는 스킨 기능을 지원합니다.
* **언어:** **日本語(기본)**, **한국어**, **English**. 모든 UI 라벨, 컨텍스트 메뉴, 대화상자, 정렬 상태, 보기 모드가 자동으로 저장되고 실행할 때 복원됩니다.

### 8. 🗛 URL 뷰어 & 폰트 자동 감지
* **URL 뷰어:** 위쪽 가운데의 + 버튼으로 URL을 추가한 뒤 Space를 눌러 확대 모드로 들어가 웹사이트에 접속합니다.
* **폰트 자동 감지:** 문서 파일 안의 폰트를 자동으로 감지해 어떤 폰트가 쓰였는지 알려 줍니다.

## ⌨️ 단축키

| 동작 | 단축키 / 제스처 |
| :--- | :--- |
| **라이트박스 미리보기 열기** | 카드에서 `Space` 또는 `더블클릭` |
| **전체 포커스 편집기 열기** | 라이트박스 안에서 `Space`를 한 번 더 |
| **다중 선택(올가미)** | 갤러리 빈 곳에서 드래그(`Ctrl + 클릭`으로 토글, `Ctrl + A`로 전체 선택) |
| **카드 순서 변경 / 폴더로 이동** | 카드를 다른 카드(수동 정렬) 또는 왼쪽 사이드바 폴더로 드래그 |
| **폴더를 하위 폴더로 넣기** | 폴더를 대상 폴더의 **가운데**로 드래그(위/아래에 놓으면 순서 변경) |
| **카드 크기 확대/축소** | `Ctrl + 마우스 휠` |
| **삭제 / 영구 삭제** | `Delete`(휴지통으로 이동) / `Shift + Delete`(즉시 삭제) |

## 🚀 설치 및 패치 방법

1. **[Releases](../../releases)** 페이지에서 최신 릴리스 ZIP을 내려받아 압축을 풉니다.
2. **`ReFanS.exe`** 를 실행합니다(독립 실행형 단일 파일이라 `.NET`을 따로 설치할 필요가 없습니다).
3. **새 버전으로 업데이트(패치):**
   * 모든 데이터(`database.json`, `folders.json`, `custom_tags.json`, `user_prefs.json`, `Images/` 와 `Media/` 폴더)는 실행 파일과 별도로 저장됩니다.
   * 새 패치가 나오면 기존 폴더의 **`ReFanS.exe`를 덮어쓰기**만 하면 되고(또는 설정에서 사용자 지정 작업 폴더를 유지), 데이터는 그대로 남습니다.
