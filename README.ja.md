## 🌐 概要

**ReFanS** は、WPF（.NET 10）で作られた、ビジュアルボード・音声/動画プレーヤー・タイポグラフィ・リファレンスファイル管理を1つにまとめたデスクトップアプリケーションです。高速なMasonryレイアウト、リアルタイムの音声/動画スクラブ、色順に並ぶ階層型タグを組み合わせています。

音楽・効果音・画像・動画・フォント・URL・文書キュレーションカードなどを視覚的に整理・タグ付け・分類できる、イメージボード＆リファレンス管理ツールです。

---

## ✨ 主な機能

### 1. 🖼️ Masonryイメージボードとマルチフォーマット対応Lightbox
* **Masonryグリッドとキュレーションビュー:** キュレーションカードと、枠のないイメージボードモードをシームレスに切り替えられます。
* **即時Lightbox（`Space` / `ダブルクリック`）:** 高解像度画像、アニメーションGIF、動画（`MP4`/`WebM`）、PDF文書（`WebView2`）、書式付きMarkdown（`.md`）ノートをプレビューできます。
* **編集ワークスペース（Lightbox内で `Space`）:** 大きな画面で、リファレンスの詳しい説明やプロフィールを入力できます。
* **自由な手動並べ替え:** 手動ソートモードでギャラリー内のカードをドラッグ＆ドロップし、ムードボードを思い通りの順番に並べたり、左側のフォルダーへドラッグして移動したりできます。

### 2. 🎧 メディアプレビューとApple Musicメタデータ連携
* **メディアプレビュープレーヤー:** 中央のイメージボード上でメディアファイル（`MP3, WAV, MP4`）を再生できます。Lightbox画面で大きく再生することも可能です。
* **オーディオ二重波形:** `.wav` と `.mp3` ファイルのPeak + RMS波形を自動で描画し、クリック＆ドラッグで即座にフレーム単位でスクラブできます。
* **Apple Music / iTunes API検索:** 高解像度のアルバムアートワーク、リリース年、作曲者メタデータ、30秒のオーディオプレビューを自動で取得します。

### 3. 📁 インタラクティブな階層・100色パレット・RGBピッカー
* **スマートなフォルダーのドラッグ:** フォルダーをドラッグして並べ替える（上端/下端）か、別のフォルダーの中央にドロップしてサブフォルダーとして入れ子にできます。
* **10x10の厳選パレット + 2D RGBスペクトル:** フォルダーアイコン、フォルダー名の文字色、階層タグ（`親/子タグ`）の色を、100種類のプリセット（ビビッド、パステル、グレートーン）またはリアルタイムのRGBスペクトルピッカーで設定できます。
* **ライブラリの分類:** ライブラリがファイルの種類ごとに自動で分類します。

### 4. 🏷️ タグ・フィルター管理、ブックマーク、ファイルロック
* **タグのドラッグ＆ドロップ:** 左側のタグをファイルへドラッグするだけで、すばやくタグを付けられます。
* **タグ管理:** タグの名前・色・階層を1つのウィンドウでまとめて管理できます。
* **ブックマークとファイルロック:** 右上のボタンから、ファイルのブックマークとロックができます（フォルダーのロックにも対応）。ファイルやフォルダーが変更されないよう保護します。

### 5. 🔍 詳細検索と画像の色抽出
* **詳細検索:** 検索バー下部のチェックボックスで、検索対象の要素（`フォルダー / タイトル / タグ / ファイルの種類 / 作成日`）を選んで検索できます。
* **画像の色抽出:** 画像ファイルの代表色を5色抽出して表示します。各カラーコードはクリップボードにコピーでき、フィルターリストにタグとして登録されて管理できます。

### 6. 📸 画面・範囲キャプチャツール
* **全画面（`📷`）と範囲切り抜き（`✂️`）キャプチャ:** ウィンドウを自動で最小化し、画面全体またはドラッグで指定した範囲をキャプチャします。代表色のスウォッチも抽出し、すぐにリファレンスとして登録します。
* **サムネイルの切り替え:** クリップボードにコピーした画像を使って、サムネイルをすばやく変更できます。

### 7. 🎨 カスタムテーマと3言語対応（設定は保持されます）
* **4つの標準テーマ:** `Default Dark`、`Gray Tone`、`Pure White`（自動コントラスト文字付き）、`Pastel Purple`。
* **カスタムテーマ:** パレット、RGBマップから色を選ぶか、画像ファイルから背景を選べるスキン機能に対応しています。
* **言語:** **日本語（既定）**、**한국어**、**English**。UIのラベル、コンテキストメニュー、ダイアログ、ソート状態、表示モードはすべて自動で保存され、起動時に復元されます。

### 8. 🗛 URLビューアーとフォント自動検出
* **URLビューアー:** 上部中央の + ボタンからURLを追加し、Spaceキーでズームモードに入ってウェブサイトにアクセスできます。
* **フォント自動検出:** 文書ファイル内のフォントを自動で検出し、どのフォントが使われているかを判別します。

## ⌨️ ショートカット

| 操作 | ショートカット / ジェスチャー |
| :--- | :--- |
| **Lightboxプレビューを開く** | カードで `Space` または `ダブルクリック` |
| **フルフォーカスエディターを開く** | Lightbox内でもう一度 `Space` |
| **複数選択（投げ縄/矩形）** | ギャラリーの空きスペースをドラッグ（`Ctrl + クリック` で切り替え、`Ctrl + A` で全選択） |
| **カードの並べ替え / フォルダーへ移動** | カードを別のカード（手動ソート時）または左サイドバーのフォルダーにドラッグ |
| **フォルダーをサブフォルダーに入れ子にする** | フォルダーを対象フォルダーの**中央**にドラッグ（上端/下端にドロップすると並べ替え） |
| **カードサイズのズーム** | `Ctrl + マウスホイール` |
| **削除 / 完全に削除** | `Delete`（ごみ箱へ移動）/ `Shift + Delete`（即時削除） |

## 🚀 インストールと更新

1. **[Releases](../../releases)** ページから最新のリリースZIPをダウンロードし、展開します。
2. **`ReFanS.exe`** を実行します（自己完結型の単一実行ファイルなので、追加の `.NET` のインストールは不要です）。
3. **新しいバージョンへの更新（パッチ適用）:**
   * すべてのデータ（`database.json`、`folders.json`、`custom_tags.json`、`user_prefs.json`、`Images/` と `Media/` フォルダー）は、実行ファイルとは別に保存されています。
   * 新しいパッチが公開されたら、既存のフォルダーの **`ReFanS.exe` を上書き**するだけ（または設定でカスタムワークスペースのディレクトリを維持）で、すべてのデータはそのまま残ります。
